নুকতা বাংলা — Mac-এ ইনস্টল করার নিয়ম
(macOS 13 Ventura বা নতুন; Apple Silicon ও Intel দুই ধরনের Mac-এই চলে)

১. NuktaBangla-x.x.x.dmg ফাইলটি খুলুন, ভেতরের "Install Nukta Bangla.pkg"-এ ডাবল-ক্লিক করুন।

২. Installer-এ Continue → Install চাপুন, পাসওয়ার্ড দিন।

৩. একবার Log Out করে আবার Log In করুন (Apple মেনু → Log Out)।

৪. System Settings → Keyboard → Input Sources → Edit… → + চাপুন।
   বাঁ দিকে Bangla বেছে নিন → "নুকতা বাংলা" → Add।

এখন মেনু বারের কিবোর্ড আইকন থেকে, বা Control + Space (অথবা fn/🌐) চেপে
ABC আর নুকতা বাংলার মধ্যে বদলাতে পারবেন।

নতুন ভার্সন পেলে: শুধু নতুন .dmg থেকে ইনস্টলারটি আবার চালান (১ ও ২)।
Developer ID সাইন ছাড়া পুরনো ভার্সন থেকে আপডেট করলে: Input Sources-এ পুরনো নুকতা বাংলা
কাজ করবে না। সেটা − চেপে সরিয়ে দিন, তারপর ৪ নম্বর ধাপে নতুনটি যোগ করুন।

লেআউট বদলাতে: মেনু বারের নু আইকনে ক্লিক করে "বিজয় লেআউট" বা "ফোনেটিক" বেছে নিন।
ফোনেটিকে ইংরেজি অক্ষরে লিখুন (ami bangla likhchi → আমি বাংলা লিখছি)। লেখার নিচে শব্দের
তালিকা আসবে: স্পেস দিলে বাছাই করা শব্দ বসবে, ↑↓ দিয়ে বাছাই বদলান, ১–৯ চেপে সরাসরি বাছুন।
অটোকারেক্ট, টাইপিং মোড, তালিকার অবস্থান: নু আইকন → সেটিংস…

মুছে ফেলতে: Input Sources থেকে নুকতা বাংলা সরান, তারপর Finder-এ
Go → Go to Folder… → /Library/Input Methods খুলে NuktaBangla.app Trash-এ ফেলুন।

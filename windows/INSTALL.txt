নুকতা বাংলা — Windows-এ ইনস্টল করার নিয়ম
(Windows 10 বা 11; 64-bit ও 32-bit দুই ধরনের কম্পিউটারেই চলে)

১. NuktaBangla-Setup.exe ফাইলটিতে ডাবল-ক্লিক করুন।
   "Windows protected your PC" দেখালে: More info → Run anyway চাপুন।

২. অনুমতি চাইলে Yes চাপুন, তারপর Next → Install → Finish।
   নুকতা বাংলা আপনার কিবোর্ডের তালিকায় নিজেই যোগ হয়ে যাবে।

৩. Windows + Space চেপে (বা টাস্কবারের ভাষার বোতাম থেকে) নুকতা বাংলা বেছে নিন।

লেআউট বদলাতে: টাস্কবারে ভাষার বোতামের পাশে বি (বিজয়) বা ফ (ফোনেটিক) দেখাবে।
একবার ক্লিক করলে লেআউট বদলাবে; রাইট-ক্লিক করলে মেনু আসবে (বিজয় লেআউট, ফোনেটিক, সেটিংস…)।
ফোনেটিকে ইংরেজি অক্ষরে লিখুন (ami bangla likhchi → আমি বাংলা লিখছি)। লেখার নিচে শব্দের
তালিকা আসবে: স্পেস দিলে বাছাই করা শব্দ বসবে, ↑↓ দিয়ে বাছাই বদলান, ১–৯ চেপে সরাসরি বাছুন,
Ctrl + Backspace চাপলে পুরো শব্দ মুছবে।
অটোকারেক্ট, টাইপিং মোড, তালিকার অবস্থান: রাইট-ক্লিক মেনু → সেটিংস…
(অথবা Start মেনু → নুকতা বাংলা সেটিংস)

নতুন ভার্সন পেলে: নতুন Setup ফাইলটি চালান। পুরনোটি তখন চালু থাকলে কম্পিউটার একবার
Restart করতে বলবে।

মুছে ফেলতে: Settings → Apps → Installed apps → নুকতা বাংলা → Uninstall।

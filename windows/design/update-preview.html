আপডেট ডায়ালগ: প্রিভিউ
• কখন দেখাবে: কম্পিউটার চালু/লগইনের পরে, বা নুকতা বাংলায় সুইচ করলে। টাইপের মাঝখানে কখনো না।
• প্রথম ১ সেকেন্ড বোতামগুলো Enter/Space-এ সাড়া দেয় না (ডান দিকের macOS প্রিভিউতে ডাউনলোড বোতাম তাই প্রথমে ঝাপসা)।
• ডাউনলোড ডিফল্ট বোতাম নয়। Esc বা ✕ মানে "পরে"।
• "পরে": পরের দিন আবার জিজ্ঞেস করবে। "বাদ দিন": পরের রিলিজ পর্যন্ত চুপ।
• "নতুন যা আছে" আসে GitHub রিলিজ নোট থেকে।
• Linux-এ একই ডিজাইন, শুধু টাইটেল বার ডেস্কটপ অনুযায়ী।
